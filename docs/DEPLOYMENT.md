# Portfolio Deployment Guide

## Live Hosting with GitHub Pages

1. Push all latest changes to `main` branch.
2. Navigate to repository settings on GitHub: `Settings > Pages`.
3. Set Source to `Deploy from a branch`.
4. Select `main` branch and `/ (root)` folder, then save.
5. Your arcade portfolio will be live at `https://<username>.github.io/simple-login-form/`.
