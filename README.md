# CyberPulse: Neon Cyberpunk Arcade

A zero-dependency vanilla JavaScript web arcade featuring interactive games built using HTML5 Canvas, Web Audio API, and modular OOP architecture.

## Included Games

- **Neon Runner**: Endless runner with physics jumping and obstacle evasion.
- **Space Defense**: Retro arcade shooter with projectile collision matrix.
- **Memory Matrix**: Pattern sequence matching game.

## Tech Stack

- HTML5 / CSS3 (Custom CRT Shaders)
- JavaScript (ES Modules, Canvas API, Web Audio API)

## Local Setup

Simply open `index.html` in any modern web browser.
